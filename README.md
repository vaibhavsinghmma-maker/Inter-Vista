# Intervista 🎯
### STAR-Based AI Interview Preparation Platform

> Practice interviews using the STAR method, answer questions verbally, and get AI-powered feedback.

---

## ✨ Features

- 🤖 AI-generated interview questions
- 🎙️ Speech-to-text answer recording
- 📊 Interview answer analysis and feedback
- 📈 Session history tracking
- 🔐 JWT Authentication system
- 🎨 Minimal modern UI with React

---

## 🛠️ Tech Stack

| Layer | Technology |
|------|-----------|
| Frontend | React, Vite, React Router |
| Backend | Node.js, Express |
| Authentication | JWT + bcrypt |
| Database | MongoDB |
| API Testing | Postman |
